# Security Policy

## Reporting Security Issues

If you discover a security vulnerability or sensitive information in Z Mic Studio, please report it via GitHub:

🔗 **https://github.com/zameersts/Z-Mic-Studio/issues**

Please include:
1. A description of the vulnerability.
2. Steps to reproduce or a proof of concept.
3. Affected versions / operating systems.

We take security seriously and will investigate and address reported issues promptly.

## Security Architecture

- **Local Network Streaming:** Audio is streamed peer-to-peer over your local Wi-Fi / Ethernet subnet.
- **No Remote Telemetry:** No user tracking, remote analytics, or recording data is transmitted to the cloud.
- **Unencrypted Local PCM:** Audio travels as plain PCM over your private local network.
